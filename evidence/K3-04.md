# K3-04. Сборка после тестов

В `Student CI` есть отдельный job `build`:

```yaml
needs: test
```

Он выполняет собственный `checkout`, потому что у каждого job отдельная
среда runner, а затем собирает образ командой:

```text
docker build -f lab/Dockerfile -t devops-student:${{ github.sha }} lab
```

При failed `test` job `build` получает статус `skipped`. При успешном
тесте оба job проходят в одном run. `${{ github.sha }}` — SHA ревизии,
обрабатываемой этим run; Docker tag является изменяемым именем, а digest
определяет конкретное содержимое образа. Образ после завершения временного
runner не сохраняется: без отправки в registry он недоступен для следующих
машин.

[Student CI #2](https://github.com/Daniil76Glushkov/DevOps-course/actions/runs/43494010700),
событие `push`, SHA
`77bb69dfcf6d17e11c928495a48b68c0f39cb337`.

Успешный run с обоими job:

`eceb98f3e66921d5424a9fecd493ebf0ea841596`. В нём видны успешные job
`test` и `build`, а tag содержит SHA этого run.
