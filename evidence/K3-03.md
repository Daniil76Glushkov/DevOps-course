# K3-03. Тестовый барьер

Проверка приложения выполняется командой:

```text
python -m unittest discover -s tests -p test_app.py -v
```

Тест `test_create_request` отправляет заявку через web, проверяет HTTP
`201`, наличие созданной записи и значение `total`. Поэтому падение этой
команды означает, что проверяемое поведение приложения не подтверждено.
Ошибку нельзя скрывать через `continue-on-error` или `|| true`.

Временный commit `77bb69d` ожидал `200` вместо `201`. Его run:
[Student CI #2](https://github.com/Daniil76Glushkov/DevOps-course/actions/runs/43494010700),
событие `push`, SHA
`77bb69dfcf6d17e11c928495a48b68c0f39cb337`. Job `test` завершился
`failed`, а зависимый `build` — `skipped`; в annotations указано
`Process completed with exit code 1`. В итоговой версии тест возвращён к
ожиданию `201`.
