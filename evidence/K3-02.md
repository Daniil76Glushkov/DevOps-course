# K3-02. Первый workflow

Workflow `Student CI` находится в
`.github/workflows/student-ci.yml`. Он запускается событиями `push` и
`pull_request` и имеет минимальное право `contents: read`.

В job `test`:

- `checkout` получает исходники проверяемой ревизии;
- `setup-python` выбирает Python 3.13;
- `python --version` выводит версию среды;
- следующий шаг запускает реальные тесты приложения.

Фактический успешный run: [Student CI #1](https://github.com/Daniil76Glushkov/DevOps-course/actions/runs/43493641777).
Событие — `push`, SHA — `5a18bad9dbb25f816abd0548f964aa815c6ec9bf`.
SHA берётся из самого run: для `pull_request` это может быть SHA результата
предполагаемого слияния, а не последний SHA ветки.
