# K3-05. Разбор ошибки pipeline

Для эксперимента временно заменяется только путь к Dockerfile:

```text
docker build -f lab/MissingDockerfile -t devops-student:${{ github.sha }} lab
```

Тест при этом должен завершиться успешно, а `build` — failed. Содержательная
причина ошибки — отсутствует файл `lab/MissingDockerfile` в контексте
checkout; это ошибка конфигурации сборки, а не ошибка поведения приложения.
После возврата пути к `lab/Dockerfile` сборка должна пройти успешно.

Ошибочный commit `77a82e2` содержит этот путь; его run:
[Course checks #3](https://github.com/Daniil76Glushkov/DevOps-course/actions/runs/43494053614),
событие `push`. Полный SHA указан GitHub в run. Исправление возвращает
`lab/Dockerfile`; итоговый Student CI run будет ссылаться на commit этого
исправления. Существенная строка лога ожидаемо имеет вид:
`failed to read dockerfile: open Dockerfile: no such file or directory`.
