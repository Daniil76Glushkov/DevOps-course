# K3-05. Разбор ошибки pipeline

Для эксперимента временно заменяется только путь к Dockerfile:

```text
docker build -f lab/MissingDockerfile -t devops-student:${{ github.sha }} lab
```

Тест при этом должен завершиться успешно, а `build` — failed. Содержательная
причина ошибки — отсутствует файл `lab/MissingDockerfile` в контексте
checkout; это ошибка конфигурации сборки, а не ошибка поведения приложения.
После возврата пути к `lab/Dockerfile` сборка должна пройти успешно.

Ошибочный commit `77a82e2` содержит этот путь; его run:
[Student CI #3](https://github.com/Daniil76Glushkov/DevOps-course/actions/runs/43494461715),
событие `push`, SHA
`77a82e2136c780f408276194bdc3236bc20a402f`. В job `build` зафиксирован
командный шаг `docker build -f lab/MissingDockerfile ...`, а job завершился
с `Process completed with exit code 1`; `test` при этом успешен. Это
подтверждает ошибку пути к Dockerfile. Исправление возвращает
`lab/Dockerfile`; исправленный итоговый run —
[Student CI #4](https://github.com/Daniil76Glushkov/DevOps-course/actions/runs/43494848095),
SHA `eceb98f3e66921d5424a9fecd493ebf0ea841596`.
